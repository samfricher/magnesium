# Drills: test-1

Short items for one gap tag, used during repair. Answers are at the end of this file.

## EXPVAL

Re-read: `Materials/Slides/unit-2-slides.md` slides 1 to 3.

1. X takes 1, 2 and 6 with probabilities 0.5, 0.3 and 0.2. Find E[X].
2. For the same X, find E[X²].

## VARSHORT

Re-read: `Materials/Slides/unit-2-slides.md` slides 5 to 6.

3. X takes 0 and 2 with probabilities 0.5 and 0.5. Find Var(X) with the shortcut.
4. X takes 1, 3 and 5 with equal probability. Find Var(X) from the definition.

## BINOM

Re-read: `Materials/Slides/unit-2-slides.md` slides 10 to 11.

5. X is Binomial(12, 0.25). Find its mean and variance.

---

## Answers

### EXPVAL

1. 0.5 + 0.6 + 1.2 = 2.3
2. 0.5 + 1.2 + 7.2 = 8.9

### VARSHORT

3. E[X²] = 2, E[X] = 1, so Var(X) = 1.
4. The mean is 3, so Var(X) = (4 + 0 + 4)/3 = 8/3.

### BINOM

5. Mean 3, variance 2.25.
