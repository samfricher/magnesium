# Screenshots for pull requests

This branch holds only images that pull requests and issues show. It is not part of Magnesium, and nothing builds from it.

- `pr-47/before`: the study window on `main` before pull request 47.
- `pr-47/after`: the study window on the branch of pull request 47.
- `pr-47/real`: the release build's real Mac window, on made-up courses.
- `issue-side-chats`: quick concept mocks for the side chat issue. They are not final designs.
- `window-polish/before`, `window-polish/after`: every page of the real window, dark and light, before and after the polish pull request.
- `session-documents/before`, `session-documents/after`: documents in a session, before and after the documents pull request.
- `session-documents/real`: documents in a session in the real window, after the review of the documents pull request.
- `session-documents/after2`, `session-documents/round2`: documents in a session after the second review, and that round's checks in the real window.
- `model-selector/before`, `model-selector/after`: a new session's first line before and after the model pick, and the states of its list, in the demo in Chrome.

- `overnight-polish/before`, `overnight-polish/after`: chosen states of the window in the demo in Chrome, on `main` and after the overnight polish pull request. `overnight-polish/real`: the real Mac window after that polish, on a made-up course.

Every image uses made-up data. If this branch is deleted, the images in those pull requests and issues stop loading.
- `frosted-glass`: the real window with frosted glass chosen, before and after, the options at each fork, the reading check over five backdrops, and the solid fallbacks. Every desktop behind the window is a made-up picture.
- `critique-1116-changes/<change>`: the seven changes from the design critique of 2026-11-16 (pull requests 107 to 113), before and after in the real window on made-up courses. `hand-*` are from hand tests of each branch's test build.
- `quirks-1116`: the study window's line, the open task's copy and the tutor's mathematics, before and after the pull request that fixed them, in the real window on a made-up course. The `math-*` pictures are from live lessons on Sonnet 5.5; the rest use the stand-in tutor.
- `review-1117/<topic>`: the changes from the window review of 2026-11-17 (today, days, steps, ruled-line, names, speed), before and after in the real window on made-up courses. Live-lesson pictures say their model in the pull request.
- `tutor-notes-142/before`, `tutor-notes-142/after`: the real window built from `main` and from the pull request for issue 142, with a stand-in tutor that sends the two notes the issue quotes around its reply. `tutor-notes-142/live`: the pull request's window in a live lesson on Sonnet 5.5 at medium effort, on a made-up course. `tutor-notes-142/stop-before`, `stop-first-version`, `stop-after`: a plain-text reply stopped part-way, on `main`, on the pull request's first version, and after its fix. `tutor-notes-142/live-opus`, `live-haiku`: the last of eight live turns on Opus 5.5 and Haiku 5.5 at medium effort.
- `instant-tab-switch/before`, `instant-tab-switch/after`: a course's page and Settings in the real window, built from `main` and from the pull request that keeps pages behind the tab in front, on a made-up course. They look the same: the change is in what each frame draws during a switch, which the pull request gives as numbers.
- `whole-course-page/before`, `whole-course-page/after`: a course's page opened from Home's list in the real window, built from the tab-switch pull request's branch and from the pull request that opens the page whole, on a made-up course. `before/first-frames.png` is what the page showed for its first frames, held on screen by slowing every runtime call by 1.2 s so it could be photographed. `after/past-the-wait.png` is the after build with the same slowed runtime, once the window stops waiting for the page's reading.
- `faster-proof`: what `app/scripts/look.mjs` prints, in the real window on a made-up course with the stand-in tutor. `look-*` are single states from one command each; `base-before` and `base-after` are one `--base` run over a throwaway style edit (wider letter spacing) that is not in the pull request.
- `tabs-home`: the real window on a made-up course: a press on a tab before and after the tab bar stopped taking the keyboard, and + opening Home in a tab that can close. `4-last-tab-closes.png`: Home as the only tab, with the close mark that closes the window.
- `space-and-plainer-copy/before`, `space-and-plainer-copy/after`: Home, Home before any space, a space's page, a mark and ⌘K's switch, in the real window built from `main` and from the pull request that names a study folder a space, on a made-up course with the stand-in tutor.
- `steady-page/before`, `steady-page/after`: the real window built from `main` (with only the new harness steps added) and from the pull request that holds the page still under the reader, on a made-up course with a stand-in tutor whose reply ends in a few seconds of "saving your work". `saving*` are taken during the save, `saved*` after it; `-soft` and `-ruled` are the other two looks of the line; the rest are on the bare line.
- `steady-page/review`: from the review of that pull request, its window on a made-up course with the stock stand-in tutor. `task-selected-typed.png`: the whole task paragraph selected and "w" typed; the task is quoted on the line and the lesson has not folded.
- `steady-page/review-fixes`: the real window on a made-up course, built from the commit the review of the steady-page pull request looked at (`-before`) and from the commit that answers it (`-after`): the line raised while the tutor saves, and typing over a task paragraph with no label.
- `steady-page/task-copy/before`, `steady-page/task-copy/after`: the copy of the open task above the line, in the real window on a made-up course with a stand-in tutor that records its tasks, built from the steady-page pull request before and after the rule that the copy comes or goes only when the learner sends, scrolls or types, or while a reply streams. `0` the task on screen, `1` a side question sent with ⌥↩ (while its reply streams, then after), `2` after "I'm lost", `3` an answer whose reply says try again without the task (after it, after a small scroll, and on typing the retry).
- `steady-page/spent-copy`: the copy of the task after "I don't know" whose reply moved on to a new task with no label, in the real window on a made-up course with a stand-in tutor that records its tasks: `before` (`4f12c69a`, the old task's copy looks current), `after` (drawn quieter until the learner acts) and `after-scroll` (the new task's copy).
- `instant-selection/before`, `instant-selection/after`: the lesson with the plan open in the real window on a made-up course, on `main` and after the pull request that made selecting, the plan and Settings fast. They are pixel for pixel the same.
- `instant-selection/second-pass/before`, `instant-selection/second-pass/after`: the lesson folded while an answer is typed (`answer-bare-typed`) and shown again with ⌘↑ (`answer-bare-looked-back`), in the real window on a made-up course, from that pull request before and after its second pass (folded replies skipped instead of removed). Each pair is pixel for pixel the same.
- `lighter-math`: the tutor's mathematics in the real window on a made-up course with a stand-in tutor, from the pull request that draws it as MathML with Temml. `heavy-1` to `heavy-6` put the same six replies of heavier mathematics side by side: `main` (KaTeX) on the left, KaTeX's own MathML in the middle (tried and not used), Temml on the right. `reply-light` and `reply-dark`: an ordinary reply, `main` on the left and Temml on the right. `close-bar` and `close-vec`: close-ups of two marks Temml still draws differently, `main` above and Temml below.
