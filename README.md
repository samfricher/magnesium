# Screenshots for pull requests

This branch holds only images that pull requests show. It is not part of Magnesium, and nothing builds from it.

- `pr-47/before`: the study window on `main` before pull request 47.
- `pr-47/after`: the study window on the branch of pull request 47.
- `pr-47/real`: the release build's real Mac window, on made-up courses.

Every image uses made-up data. If this branch is deleted, the images in those pull requests stop loading.
